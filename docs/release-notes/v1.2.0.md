# Release v1.2.0: "Hyper-Resilience & Enterprise Grade"

**Date:** 2026-01-08
**Status:** Release Candidate

## 🌟 Highlights

### 🚀 Massive Performance Upgrade
-   **High-Throughput Backend**: Implemented Buffer Pooling and smart Log Sampling (`AccessLogSampleRate`), boosting throughput by ~5.5x under load (Story-80).
-   **Virtualized Traffic Inspector**: The Traffic UI now handles 5,000+ events smoothly using virtual scrolling, eliminating DOM lag (Story-81).

### 🛡 Enterprise Security & Compliance
-   **Privacy-First Logging**: All user emails are automatically masked in logs (e.g., `u***@host.com`).
-   **Internal Identity Resolution**: Securely resolves Google internal Project IDs for enterprise compliance (Story-77).
-   **Zero-Knowledge Cloud Sync**: Encrypted profile syncing via Supabase (Story-33).

### 🌉 Universal IDE Support
-   **Beyond VS Code**: Added native support for **Cursor** and **Windsurf** IDEs.
-   **Zero-Config Injection**: Automatically detects running IDEs and injects auth tokens without manual setup (Story-90).

## 📋 Full Changelog

### ⚡️ Proxy Engine
-   **Native Gemini Protocol**: Full support for `gemini-1.5-pro` and `gemini-ultimate` passthrough.
-   **Resilience**: Smart retries, round-robin key rotation, and "Daily" environment fallback.
-   **Codex Compatibility**: Legacy `/v1/completions` handler for older Copilot clients (Story-65).
-   **WebSocket Inspection**: View real-time WebSocket frames for advanced debugging.

### 👤 Account Management
-   **Multi-Account Switcher**: Seamlessly switch between Free, Pro, and Enterprise accounts.
-   **Tier Badges**: Visual indicators for account capabilities.
-   **Legacy Import**: Auto-import existing `siberia.json` configurations.

### 🛠 Developer Tools
-   **Traffic Monitor**: Real-time request/response inspection with body capture and regex filtering.
-   **Z.ai Integration**: Built-in MCP Server with Web Search and Vision tools.
-   **Terminal Helper**: `siberia set-env` command for easy shell configuration.

### 🐛 Bug Fixes
-   Fixed Wails build pipeline failures.
-   Resolved "Thinking Block" parsing issues for Claude 3.5 Sonnet.
-   Fixed memory leaks in long-running stream captures.

1.  Download `Siberia_1.2.0_universal.dmg`
2.  Drag to Applications.
3.  Run Siberia.

### Manual Build
```bash
git checkout v1.2.0
cd apps/backend
wails build
```
